# Software Requirements

- R 4.2.2
- R package `survey` 4.4.2
- R package `jsonlite` 1.8.8
- Python 3 with `pandas` and `numpy`

The analysis uses deterministic Fay balanced repeated replication with rho 0.5 and `mse=TRUE`. Users should record their own environment and package versions when reproducing the protected local computation.
