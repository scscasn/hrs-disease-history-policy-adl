# Data Use and Disclosure

This repository is code-only. It contains no HRS participant-level data, row-level derivatives, record-specific identifiers, restricted files, access credentials, or source data archive.

The RAND HRS Longitudinal File 1992–2022 v1 Early Release product must be obtained directly from the Health and Retirement Study by eligible users under the applicable registration and Conditions of Use. The Early Release data have not completed final cleaning and may contain errors corrected in a later Final Public Release.

The repository code accepts user-supplied local source and correction-list paths only. The record-specific correction list must be created locally from the applicable official HRS data alert and remains outside version control. Any protected local input or derived output must be excluded from version control and must not be uploaded to AI services. Only the authors' non-disclosive manuscript results are reported in the accompanying paper and supplement.
