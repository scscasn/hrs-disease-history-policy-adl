# Release notes — v1.0.0

Release date: 29 September 2026

## What this release contains

- Analytic code for the frozen policy-comparison workflow.
- An independent primary-estimate audit script.
- The frozen analysis specification, correction record, software requirements, and a disclosure-oriented variable dictionary.

## What this release does not contain

This is not a data release. It contains no HRS microdata, row-level derived files, record-specific identifiers, credentials, restricted materials, or source archive. The public scripts require an independently obtained, authorized RAND HRS source archive and a locally maintained correction list derived from the applicable official HRS data alert. Both inputs must remain outside version control.

## AI and protected-data boundary

The authors manually reran the release-version workflow in a local non-AI environment. AI assistance was limited to language drafting, code drafting and review, document formatting, and consistency checks of non-disclosive aggregate outputs. HRS person-level data and row-level derivatives were not uploaded to, shared with, processed, or analyzed by AI tools; AI tools did not index directories containing them.

## Reproduction scope

The recorded primary result is the practical-equivalence assessment for the prespecified paired per-condition association contrast. The reproduction record documents the verified numerical result and the code environment. It does not imply that the public repository distributes HRS data or grants access to HRS products.
